# Расчет по проекту

## 1. Назначение

Раздел «Расчет по проекту» предназначен для составления сметы на основе готового проекта дома. В отличие от «Калькулятора», где количество материалов вычисляется автоматически по размерам дома, здесь вы сами указываете необходимое количество каждого материала. Это идеальный инструмент для тех, у кого уже есть готоваязация и спецификация материалов.

## 2. Доступ к разделу

1.  После входа в систему вы попадаете на главный экран.
2.  В левом боковом меню выберите пункт **«Расчет по проекту»**.
    *   Выбранный пункт меню будет выделен цветом.
    *   В заголовке страницы отобразится «Расчет по проекту».

## 3. Работа с формой

Вся работа происходит в карточке **«Параметры дома»**.

### 3.1. Выбор типа дома и фундамента

1.  **Тип дома**: Выберите тип здания из выпадающего списка. **От этого выбора зависит, какие именно материалы появятся в форме ниже.**
    *   *Например, для типа «Брусовой» появятся поля для выбора бруса для сруба, нижней обвязки, межвенцового утеплителя и т.д.*
2.  **Тип фундамента**: Выберите тип фундамента. Это также повлияет на набор материалов (например, появятся поля для выбора свай и оголовков).

### 3.2. Управление проектами

*   **Сохранение**: Чтобы сохранить текущий проект, нажмите кнопку **«Сохранить»** в правом верхнем углу карточки.
*   **Загрузка**: Чтобы загрузить ранее сохраненный проект, нажмите кнопку **«Загрузить»**. Цифра в скобках (например, «(1)») показывает количество доступных сохраненных проектов.

### 3.3. Заполнение спецификации материалов

После выбора типа дома и фундамента в нижней части формы появляются блоки для ввода данных по материалам. Каждый блок соответствует определенной конструктивной роли (например, «Брус для сруба», «Стропила», «Утеплитель»).

Каждый блок устроен следующим образом:

1.  **Выбор материала (первое поле):** Нажмите на выпадающий список, чтобы выбрать конкретный материал из доступных вариантов (например, «Брус 200×200 мм», «Доска обрезная 50×200 мм»).

2.  **Количество (второе поле):** Введите необходимое количество материала.
    *   Рядом с полем указана единица измерения (например, `м³`, `м²`, `шт`, `пог.м`).
    *   Вы можете изменять значение с помощью кнопок «+» и «-» или ввести его вручную.

3.  **Цена работы (третье поле):** Укажите стоимость работ за одну единицу материала. Это позволяет разделить затраты на материал и на работу по его монтажу.
    *   Например, вы указали 10 м³ бруса, цену материала 12 600 руб./м³ и цену работы 1 000 руб./м³. Итоговая стоимость по этой позиции будет рассчитана как `10 * (12 600 + 1 000) = 136 000 руб.`
    *   Рядом с полем выведена подсказка в виде знака вопроса, поясняющая его назначение.

**Важно:** В этом режиме количество материала не рассчитывается автоматически — вы должны ввести его вручную, основываясь на своем проекте.

### 3.4. Получение результата

После заполнения всех необходимых полей:

1.  Нажмите на большую синюю кнопку **«Рассчитать стоимость»** внизу формы.
2.  Дождитесь окончания расчета.
3.  Результаты расчета отобразятся ниже в карточке **«Результат расчёта»**.

    В результатах вы увидите детальную таблицу со сметой, где сгруппированы:
    *   Каждый выбранный вами материал и соответствующая работа.
    *   Указанное вами количество.
    *   Цена за единицу.
    *   Итоговая стоимость по каждой позиции.
    *   Общий итог по смете.

    Строки в таблице можно сворачивать и разворачивать для удобного просмотра.

## 4. Возможные действия после расчета

*   Вы можете вернуться к форме и **изменить параметры** (например, скорректировать количество материала или выбрать другой тип бруса), а затем нажать «Рассчитать снова» — результат обновится.
*   Сохранить финальный или промежуточный расчет, нажав кнопку **«Сохранить»**.
*   Скачать смету в формате Excel, нажав кнопку **«Скачать Excel»** в карточке результатов.
*   Чтобы перейти к другим разделам, используйте левое боковое меню или кнопку «Назад» (стрелка влево) рядом с заголовком страницы.

## 5. Часто задаваемые вопросы (FAQ)

**Вопрос:** Чем этот раздел отличается от «Калькулятора»?  
**Ответ:** В «Калькуляторе» количество материалов рассчитывается автоматически по введенным вами габаритам дома. В разделе «Расчет по проекту» вы сами вводите точное количество каждого материала, что идеально подходит для работы с готовой проектной документацией.

**Вопрос:** Зачем нужно указывать «Цену работы» отдельно?  
**Ответ:** Это позволяет получить более детальную смету, понимая, какая часть затрат идет на материалы, а какая — на оплату труда строителей.

**Вопрос:** В каких единицах измерения вводить количество?  
**Ответ:** Единица измерения указана рядом с полем ввода для каждого материала. Она может быть разной: кубические метры (м³), квадратные метры (м²), штуки (шт) или погонные метры (пог.м). Внимательно следите за этим при заполнении.

**Вопрос:** Как удалить сохраненный проект?  
**Ответ:** Управление сохраненными проектами (просмотр, удаление) осуществляется в окне «Загрузить». Нажмите кнопку **«Загрузить»**, и в открывшемся списке у каждого сохраненного проекта будет кнопка для его удаления.
