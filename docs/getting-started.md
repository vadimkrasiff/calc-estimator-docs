# Начало работы

Добро пожаловать в документацию **ДомЛайк**! В этом разделе вы узнаете, как зарегистрироваться, войти в систему и выполнить свой первый расчёт материалов для строительства дома.

---

## 🔐 Регистрация и вход

### Регистрация нового пользователя

Приложение работает в закрытом режиме. Доступ предоставляется **по приглашению администратора**.

#### Как это работает:

```
1. Администратор добавляет ваш email в систему
2. Вы получаете письмо со ссылкой для регистрации
3. Переходите по ссылке и задаёте пароль
4. Готово! Можно входить в систему
```

---

#### 📧 Пример пригласительного письма:

```
Тема: Приглашение в систему ДомЛайк

Добро пожаловать!

Вы были приглашены в систему ДомЛайк — калькулятор расчёта
строительных материалов.

🔗 Ссылка для регистрации:
https://example.com/register?invitation=INVITATION_TOKEN

⏰ Ссылка действительна 24 часа.

Если вы не запрашивали доступ — просто проигнорируйте это письмо.

С уважением,
Команда vkrasiv.ru
```

---

#### ✅ Завершение регистрации:

```
1. Откройте письмо от `noreply@vkrasiv.ru`
2. Нажмите на ссылку регистрации (или скопируйте её в браузер)
3. На странице регистрации задайте пароль:
   - Минимум 8 символов
   - Желательно: буквы + цифры + спецсимволы
4. Подтвердите пароль
5. Нажмите "Зарегистрироваться"
6. Вы будете автоматически перенаправлены на страницу авторизации
```

:::info Важно
- Ссылка действительна **24 часа** с момента отправки
- Ссылка **одноразовая** — после регистрации она становится неактивной
- Если ссылка истекла — запросите новую у администратора
:::

---

### Вход в систему (после регистрации)

```
1. Откройте адрес ДомЛайка, который выдал администратор, и перейдите на страницу входа.
2. Введите ваш email и пароль
3. Нажмите "Войти"
4. Вы попадёте в личный кабинет / калькулятор
```

:::tip Совет
Используйте менеджер паролей (Bitwarden, 1Password, KeePass) для безопасного хранения учётных данных.
:::

---

## 🔄 Если что-то пошло не так

| Проблема | Решение |
|----------|---------|
| ❌ "Ссылка истекла" | Запросите новую ссылку у администратора |
| ❌ "Неверный токен" | Убедитесь, что скопировали ссылку полностью |
| ❌ Письмо не пришло | Проверьте папку "Спам" / "Промоакции" |
| ❌ "Пользователь уже существует" | Нажмите "Войти" |

**Не получается?** Напишите в поддержку:
- 📧 support@vkrasiv.ru
- 💬 Telegram: @vkrasiv_support


## 🧮 Первый расчёт: пошаговая инструкция

### Шаг 1: Перейдите в калькулятор

После входа в систему:
- Нажмите на пункт **"🧮  Калькулятор"** в боковом меню

---

### Шаг 2: Выберите тип дома

На первом экране выберите тип конструкции:

| Тип дома | Статус | Описание |
|----------|--------|----------|
| 🪵 **Брусовой дом** | ✅ Доступно | Полный расчёт: стены, перекрытия, крыша, фундамент |
| **Каркасный** | Доступен в форме | Для расчёта заполните каталог каркасных материалов и цен |
| **Газобетон** | Доступно | Наружные стены, перегородки и клей по ценам каталога |

Для первого расчёта газобетона используйте [пример дома 6 × 6 м](./calculator.md#aerated-house-example) с параметрами, скриншотами и контрольной сметой.

Если в проекте предусмотрена лента, заполните [размеры ленточного фундамента](./calculator.md#strip-foundation).

---

### Шаг 3: Введите параметры дома

Заполните основные геометрические параметры:

| Параметр | Пример | Описание |
|----------|--------|----------|
| **Длина** | `10` | Длина дома по внешней стороне |
| **Ширина** | `8` | Ширина дома по внешней стороне |
| **Этажность** | `2` | Количество полноценных этажей |
| **Высота потолков** | `3` | Высота от пола до потолка |
| **Тип крыши** | `Двускатная` | Двускатная / вальмовая / односкатная |
| **Высота конька** | `2.5` | Высота крыши от перекрытия |
| **Тип фундамента** | `Ленточный` | Свайный / ленточный / плитный |

---

### Шаг 4: Выберите материалы

Для каждого конструктивного элемента выберите материал из справочника:

```
🪵 Стены:
  [▼ Брус профилированный 150×150 мм]

📏 Лаги пола:
  [▼ Брус 100×200 мм]

🪚 Черновой пол:
  [▼ Доска обрезная 40×150 мм]

🧵 Утеплитель:
  [▼ Минеральная вата 200 мм]

🏠 Кровля:
  [▼ Профнастил С-21]
```

**Как выбрать материал:**
1. Нажмите на выпадающий список
2. Найдите нужный материал по названию или размерам
3. Кликните для выбора

> **ℹ️ Примечание:** Справочник материалов управляется на отдельной странице. Если нужного материала нет в списке — перейдите на необходимую страницу.

---

### Шаг 5: Настройте дополнительные параметры

Расширенные настройки для точности расчёта:

```
⚙️ Дополнительные настройки:

💰 Стоимость работ:
    Указажите отдельно для каждого материала
```

---

### Шаг 6: Выполните расчёт

1. Проверьте введённые данные
2. Нажмите кнопку **"🧮 Рассчитать стоимость"**
3. Дождитесь обработки
4. Результаты отобразятся на экране (пролестайте вниз)

## 💾 Сохранение как шаблон

### Сохранить текущий расчёт

```
1. На странице результатов нажмите "💾 Сохранить шаблон"
2. Введите название: например "Дом 10×8 брус 2 этажа"
3. (Опционально) Добавьте описание
4. Нажмите "Сохранить"
```

**Что сохраняется:**
- ✅ Все параметры дома
- ✅ Выбранные материалы
- ✅ Настройки коэффициентов
- ✅ Стоимость работ (если указана)

---

### Загрузить существующий шаблон

```
1. На странице калькулятора нажмите "📂 Загрузить шаблон"
2. Выберите шаблон из списка ваших сохранений
3. Параметры заполнятся автоматически
4. При необходимости измените данные
5. Нажмите "🧮 Рассчитать" для пересчёта
```

**Преимущества шаблонов:**
- 🔄 Быстрый пересчёт похожих проектов
- 📊 Сравнение разных вариантов материалов
- 📋 Стандартизация расчётов для типовых проектов
